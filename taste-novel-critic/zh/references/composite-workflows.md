# Composite Workflows · taste-novel-critic

> 这是 `../SKILL.md` 的延伸参考。主 skill 提供诊断协议；本文件含诊断完成后的可选复合工作流（改写指引 / 章节自检 / 大纲重构）。

诊断之后用户常需要做下一步：**改写段落 / 章节自检 / 重构大纲**。三节工具，不替写。

# 子节 1 · 诊断后改写指引

**用于**：维度 4（细节执行）命中、用户问"怎么改"。维度 1-3 命中先回子节 3，不在句子层动手。

**修稿四步**（按顺序，不可跳）
1. **删套话** — 砍「他意识到……」「也许，这就是……」「空气仿佛凝固了」「眼中闪过……」「他不禁……」「第一、第二、第三……」。
2. **删重复解释** — 同一信息出现 ≥ 2 次 → 砍到只留 1 次，选最锋利那句。
3. **删无效心理描写** — 紧张时刻的"系统化内心分析"改为 1 个本能反应（攥拳、停步、缩手）。
4. **提纯动作场景** — 动作替代结论；细节替代情绪标签；人物反应替代作者说明；因果链替代"突然想通"。

**M1 替代原则**
- 形容词标签 → 具体动作。「怒不可遏」→「把茶杯捏到指节发白」。
- 总结腔 → 场景化结果。「她意识到被骗」→「她退后半步，眼睛盯住门把手」。
- "不是 X，是 Y"排比 → 砍到单次配具体比喻。可保留：「不是冰冷，是像握着隔夜的馒头」；必砍：连用三句解释同一感觉。

**反灌水自检**：删一段后若主线 / 人物 / 伏笔 / 气氛任一未受影响 → 是水。

# 子节 2 · 章节级 self-review checklist

**用于**：用户拿整章问"这章能发吗"、四维诊断全过仍犹豫时的结构化门禁。

**8 维度审核**（任一 fail 即不算 pass）

| 维度 | 看什么 | 失败信号 |
|---|---|---|
| 高光 | 至少一处可记忆场面 | 平推、无记忆点 |
| 一致性 | 设定/人物/因果闭合 | 前后打架、人物失真 |
| 节奏 | 推进且不拖 | 解释过多、事件太少 |
| 钩子 | 章末有继续读的理由 | 无悬念、无风险、无回报 |
| 暗线 | 既有伏笔有动静 | 长线停摆、回收突兀 |
| 爽点 | 可感知收获 | 只铺垫不兑现 |
| 反 AI | 无模板腔总结腔 | 套话密集 |
| 反过度解释 | 同一信息不反复解释 | "不是 X，是 Y"连发、感觉描写超 3 句无推进 |

**结论**：`pass` / `revise`（用子节 1 修）/ `rewrite`（回子节 3）。

**快速过线 5 条**：主角有目标 / 冲突有推进 / 至少 1 个高光或钩子 / 无致命一致性问题 / 套话 ≤ 2 处每千字。

**过度解释检测**（最易漏的 AI 味）
- "不是 X，是 Y"同段 ≥ 2 次 → 必砍。
- 感觉描写连续 ≥ 3 句无场景推进 → 换 1 个身体动作。
- 紧张时刻"系统化内心分析"（"这是 A 不是 B，因为 C 所以 D"）→ 换本能反应。

# 子节 3 · 大纲诊断与重构框架

**用于**：M2 / M3 / 反模式 2 命中、连续 2-3 章失速、问题不在句子层。改完大纲后用子节 2 验章节。

**优先级**（从大到小）
1. **卷阶段目标** — 当前卷有无明确阶段目标和卷末兑现？无 → 立刻补。
2. **单元三段** — 每单元含「入口问题 / 中段升级 / 阶段结果」？缺一段必失速。
3. **三线推进** — 明线 / 暗线 / 世界揭示，每章至少占两项。只占一项 → 中间章。
4. **因果而非事件** — 大纲只列事件不写承接 → 正文必空转。

**单元节奏**：铺局 2-3 章 → 升级 2-4 章 → 兑现 1-2 章。

**黄金前三章**
- 第 1 章 — 主角是谁 / 世界哪里不对 / 故事为什么必须开始。
- 第 2 章 — 核心机制 / 核心异质感 / 当前秩序的代价。
- 第 3 章 — 阶段性高潮 / 真相切片 / 更大的门缝。

**失速清单**（命中即必改）：连续 2 章只解释设定 / 连续 3 章没有新风险 / 每章都是中间章 / 钩子只靠"突然有人来敲门"。

**设定改动前必问**（命中 M1 / 反模式 3）：影响主角能力边界？让旧章节失效？让反派动机不成立？和已铺伏笔冲突？
